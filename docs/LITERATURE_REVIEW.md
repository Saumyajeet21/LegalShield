# Initial literature comparison

| Work | Scope and implication |
| --- | --- |
| ContractNLI | Document-level labels and discontiguous evidence support the verifier benchmark. It documents harder exception/negation cases. |
| LegalBench-RAG | Expert evidence snapshots support retrieval metrics. The source corpus overlaps training candidates. |
| LegalAssist | Authority ranking, temporal validity and abstention are prior art. Compare its scope before making any authority-aware architecture novelty claim. |
| RGB and counterfactual risk control | Counterfactual RAG tests and uncertainty-aware prompting have precedent. Independently established legal provenance is the variable of interest here. |
| BIPIA | External indirect prompt injection research, with a non-legal task scope. |
| Self-RAG and semantic entropy | Adaptive retrieval/self-verification and sampled answer uncertainty have precedents. LAVEN integrates an independent verifier and typed evidence records. |
| LegalRuleML | Norms, sources and defeasibility predate this work. LAVEN supports a small bounded reasoning subset. |

Potential contribution: a reviewed paired legal-authority intervention with
correct change and correct invariance measured jointly and at matched coverage.
